# Week 9 lab — instructor solutions

This folder holds the Week 9 **solutions**:

```
COMP9085_Week09_Lab_Solutions.ipynb   - complete, executed, with real output, worked answers and instructor notes
COMP9085_Week09_Lab_Solutions.html    - the same notebook, rendered
```

Both are built by `data/scripts/23_build_week09_lab.py` and are **gitignored**: they never reach
the public repository or the website. They are released to students on Canvas after the lab.
Only this README is tracked. When the solutions are built, a check cell asserts that their outputs
agree with `data/scripts/week09_numbers.json`, the numbers quoted by the lecture and the website.
