# Week 6 lab — instructor solutions

This folder holds the Week 6 **solutions**:

```
COMP9085_Week06_Lab_Solutions.ipynb   - complete, executed, with real output and worked answers
COMP9085_Week06_Lab_Solutions.html    - the same notebook, rendered
```

Both are generated together with the lab notebook, from the same source, by
`data/scripts/14_build_week06_lab.py`, so the two cannot drift apart. The build
executes the solutions in a fresh kernel and checks their outputs against
`data/scripts/week06_numbers.json`, the source the lecture quotes.

**This folder is `.gitignore`d** (see the repository's `.gitignore`, "Instructor-only
lab solutions"); only this README is tracked, and nothing on the public website links
into it. Release the solutions on Canvas after the lab if you wish. The lab notebook one
directory up contains no answers.
