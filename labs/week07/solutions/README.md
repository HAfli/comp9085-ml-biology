# Week 7 lab — instructor solutions

This folder holds the Week 7 **solutions** (refreshed 2026/27 lab):

```
COMP9085_Week07_Lab_Solutions.ipynb   - complete, executed, with real output, worked answers and instructor notes
COMP9085_Week07_Lab_Solutions.html    - the same notebook, rendered
```

Both are generated together with the lab notebook, from one source, by
`data/scripts/21_build_week07_lab.py`, so the two cannot drift apart. The build executes the
solutions in a fresh kernel and checks their outputs against
`data/scripts/week07r_numbers.json` (written by `20_build_week07_refresh.py`), the source the
lecture and the website quote.

**This folder is `.gitignore`d** (see the repository's `.gitignore`, "Instructor-only lab
solutions"); only this README is tracked, and nothing on the public website links into it.
Release the solutions on Canvas after the lab if you wish. The lab notebook one directory up
contains no answers.
