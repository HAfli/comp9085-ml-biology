# Week 5 lab — worked solutions (released on Canvas after the lab)

This folder holds the Week 5 **worked solutions**:

```
COMP9085_Week05_Lab_Worked_Solutions.ipynb   - complete, executed, with real output
COMP9085_Week05_Lab_Worked_Solutions.html    - the same notebook, rendered
```

Both are generated together with the lab notebook, from the same source, by
`data/scripts/12_build_week05_lab.py`, so the two can never silently drift
apart.

The worked solutions are written for students, but they are released on
**Canvas after the lab**, not on this public site. **This folder is
`.gitignore`d** (see the repository's `.gitignore`, "Instructor-only lab
solutions"), and nothing on the public website links into it. The lab
notebook one directory up contains no answers and is the only Week 5 lab
notebook the public site serves.
