# Week 10 lab — instructor solutions

This folder holds the Week 10 **solutions**:

```
COMP9085_Week10_Lab_Solutions.ipynb   - complete, executed, with real output, worked answers and instructor notes
COMP9085_Week10_Lab_Solutions.html    - the same notebook, rendered
```

Both are built by the Week 10 lab builder, which is kept with the instructor materials because it contains the answers, and are **gitignored**: they never reach
the public repository or the website. They are released to students on Canvas after the lab.
Only this README is tracked. When the solutions are built, a check cell asserts that their outputs
agree with `data/scripts/week10_numbers.json`, the numbers quoted by the lecture and the website.
